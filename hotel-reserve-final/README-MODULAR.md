# 🏨 افزونه رزرو هتل وردپرس - نسخه ماژولار

## 📋 توضیحات

این افزونه یک سیستم کامل و حرفه‌ای برای رزرو هتل با معماری ماژولار است که امکان فعال/غیرفعال کردن بخش‌های مختلف را فراهم می‌کند.

## ✨ ویژگی‌های اصلی

### 🎯 معماری ماژولار
- **ماژول اتاق‌ها**: نمایش اتاق‌ها با طراحی کارتی زیبا و ریسپانسیو
- **ماژول جستجو**: باکس جستجوی پیشرفته با تاریخ شمسی
- **ماژول امکانات**: نمایش امکانات و خدمات هتل
- **ماژول قوانین و کنسلی**: نمایش قوانین رزرو و سیاست کنسلی

### 🎨 طراحی و UI/UX
- طراحی مدرن با گرادیانت‌های زیبا
- ریسپانسیو 100% برای موبایل، تبلت و دسکتاپ
- انیمیشن‌های روان و حرفه‌ای
- نمایش کاروسلی اتاق‌ها در موبایل برای تجربه کاربری بهتر

### 💰 سیستم قیمت‌گذاری پیشرفته
- قیمت‌گذاری روزانه برای هر اتاق
- **قابلیت انتخاب بازه تاریخ (1 تا 30+ روز)**
- اعمال قیمت یکجا برای چندین روز
- مدیریت آسان قیمت‌ها در پنل ادمین
- پشتیبانی از تقویم شمسی

### ⚙️ پنل تنظیمات جامع
- فعال/غیرفعال کردن هر ماژول به صورت جداگانه
- انتخاب نوع نمایش اتاق‌ها (Grid, List, Carousel)
- تنظیم واحد پول
- و بسیاری تنظیمات دیگر...

## 📦 نصب و راه‌اندازی

### پیش‌نیازها
- WordPress 5.0 یا بالاتر
- WooCommerce 3.0 یا بالاتر
- PHP 7.2 یا بالاتر

### مراحل نصب
1. فایل افزونه را در پوشه `wp-content/plugins/` آپلود کنید
2. از پنل مدیریت وردپرس، افزونه را فعال کنید
3. به **محصولات > تنظیمات رزرو** بروید و ماژول‌های مورد نظر را فعال کنید

## 🚀 نحوه استفاده

### 1. ایجاد هتل جدید
1. از منوی **محصولات** یک محصول جدید ایجاد کنید
2. به تب **اتاق‌های هتل** بروید
3. سیستم رزرو هتل را فعال کنید
4. اتاق‌های خود را اضافه کنید

### 2. تنظیم اتاق‌ها
برای هر اتاق می‌توانید تنظیم کنید:
- نام اتاق
- ظرفیت (تعداد نفرات)
- تعداد تخت
- متراژ
- قیمت پایه
- تصویر اتاق
- توضیحات

### 3. قیمت‌گذاری پیشرفته

#### روش 1: قیمت‌گذاری تک روز
1. در پنل مدیریت هتل، روی دکمه **قیمت‌گذاری** کلیک کنید
2. روی روز مورد نظر کلیک کنید
3. قیمت را وارد کنید

#### روش 2: قیمت‌گذاری بازه تاریخی (جدید!)
1. روی دکمه **افزودن بازه قیمتی** کلیک کنید
2. تاریخ شروع و پایان را انتخاب کنید
3. قیمت برای همه روزهای این بازه را وارد کنید
4. ذخیره کنید

**مثال**: برای تعطیلات نوروز (1-15 فروردین)، می‌توانید یکجا برای 15 روز قیمت تعیین کنید.

### 4. تنظیم ماژول‌ها
از منوی **محصولات > تنظیمات رزرو**:

#### ماژول اتاق‌ها
- فعال/غیرفعال کردن
- نوع نمایش: Grid (شبکه‌ای)، List (لیستی)، Carousel (کاروسل)
- نمایش/عدم نمایش تصاویر اتاق‌ها

#### ماژول جستجو
- فعال/غیرفعال کردن باکس جستجو
- شامل: انتخاب تاریخ ورود/خروج، تعداد مهمان، انتخاب اتاق

#### ماژول امکانات
- نمایش امکانات هتل (وای‌فای، پارکینگ، استخر، ...)
- آیکون‌های زیبا برای هر امکانات

#### ماژول قوانین
- زمان ورود و خروج
- سیاست کنسلی
- قوانین هتل

## 📱 ریسپانسیو و موبایل

### ویژگی‌های موبایلی
- تبدیل خودکار نمایش اتاق‌ها به حالت کاروسل در موبایل
- اسکرول افقی با snap برای تجربه کاربری بهتر
- دکمه‌های بزرگ‌تر برای لمس آسان‌تر
- فونت‌ها و فاصله‌ها بهینه برای موبایل

### نقاط شکست (Breakpoints)
- **Desktop**: بالای 1024px - نمایش Grid کامل
- **Tablet**: 768px - 1024px - نمایش 2 کارت در هر ردیف
- **Mobile**: زیر 768px - نمایش کاروسل
- **Small Mobile**: زیر 480px - بهینه‌سازی بیشتر

## 🎨 سفارشی‌سازی ظاهر

### رنگ‌ها
رنگ‌های اصلی در فایل CSS با متغیرهای CSS قابل تغییر هستند:

```css
:root {
    --wchr-primary: #667eea;      /* رنگ اصلی */
    --wchr-secondary: #764ba2;    /* رنگ ثانویه */
    --wchr-success: #10b981;      /* رنگ موفقیت */
    --wchr-danger: #ef4444;       /* رنگ خطا */
}
```

### لایوت‌ها
سه نوع لایوت برای نمایش اتاق‌ها:
1. **Grid**: نمایش شبکه‌ای (پیش‌فرض)
2. **List**: نمایش لیستی (برای جزئیات بیشتر)
3. **Carousel**: نمایش کاروسل (بهترین برای موبایل)

## 🔧 توابع Developer

### چک کردن فعال بودن ماژول
```php
if (WCHR_Settings::is_module_enabled('rooms')) {
    // ماژول اتاق‌ها فعال است
}
```

### دسترسی به ماژول‌ها
```php
$wchr = WC_Hotel_Reserve_Modular::get_instance();
$rooms_module = $wchr->get_module('rooms');
```

## 🐛 رفع مشکلات رایج

### مشکل 1: ماژول‌ها نمایش داده نمی‌شوند
**راه حل**: به **محصولات > تنظیمات رزرو** بروید و ماژول‌های مورد نظر را فعال کنید.

### مشکل 2: استایل‌ها درست نیست
**راه حل**: کش مرورگر و کش وردپرس را پاک کنید.

### مشکل 3: قیمت‌گذاری کار نمی‌کند
**راه حل**: مطمئن شوید JavaScript خطایی ندارد (F12 > Console را چک کنید).
